# CineMatch

Projet JavaScript (React + Vite) qui utilise l'API [TMDB](https://www.themoviedb.org/) pour parcourir et rechercher des films.

## Installation

```bash
npm install
cp .env.example .env.local
```

Renseignez ensuite votre clé API TMDB (v3) dans `.env.local` :

```
VITE_TMDB_API_KEY=votre_cle
```

## Lancer le projet

```bash
npm run dev
```

## Scripts

- `npm run dev` : serveur de développement
- `npm run build` : build de production
- `npm run lint` : analyse du code
